# ⏳ Cronos — Sistema de Agendamento

O **Cronos** é um projeto de site de agendamento desenvolvido com o objetivo de explorar a criação de aplicações web e colocar em prática conceitos de desenvolvimento front-end e back-end.

Durante o desenvolvimento, utilizei a **inteligência artificial como ferramenta de apoio ao aprendizado**, auxiliando na compreensão de funcionalidades, na resolução de dúvidas e na aplicação de conceitos em HTML, CSS e PHP.

## 🎯 Objetivos do projeto

- Desenvolver uma aplicação web voltada para agendamentos.
- Aprimorar meus conhecimentos em HTML, CSS e PHP.
- Aprender a implementar funcionalidades utilizando a inteligência artificial como ferramenta de estudo.
- Compreender melhor a estrutura e o funcionamento de aplicações web.
- Desenvolver habilidades de resolução de problemas e aprendizado independente.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e organização visual da interface.
- **PHP:** aprendizado e implementação de funcionalidades no back-end.
- **Inteligência Artificial:** apoio ao aprendizado, à compreensão de conceitos e ao desenvolvimento de funcionalidades.

## 📚 Aprendizados

O desenvolvimento do Cronos foi uma oportunidade de aprofundar meus conhecimentos em desenvolvimento web, explorando a integração entre diferentes tecnologias.

A utilização da inteligência artificial fez parte do meu processo de aprendizagem, permitindo investigar soluções, compreender trechos de código e aprender novas formas de implementar funcionalidades.

Mais do que desenvolver um site, o projeto representou uma oportunidade de aprender na prática, experimentar soluções e evoluir minhas habilidades como desenvolvedora.

## 🚀 Próximos passos

O projeto pode continuar evoluindo com a implementação de novas funcionalidades, melhorias na interface e aprimoramentos na lógica de agendamentos.
